## From Software Archipelago Clients

This is a shared repo for several From Software Archipelago clients that share the same underlying infrastructure. It currently has a W.I.P of the eldenring client inside of it.

See [archipelago.gg] for general information about Archipelago

Other FromSoft Archipelago Clients
This isn't the only Archipelago mod for From Software games! Here are others that I know of:


* [Armored Core](https://github.com/JustinMarshall98/Armored-Core-PSX-Archipelago)
* [Dark Souls Remastered](https://github.com/ArsonAssassin/DSAP)
